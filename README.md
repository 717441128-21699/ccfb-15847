# 十米台跳水 · 多刚体物理游戏

基于 **WebGL2 + TypeScript** 的 10 米跳台跳水游戏。运动员建模为 10 节刚体（头、躯干、左右上臂、前臂、大腿、小腿），
腾空阶段无外力矩，靠改变身体姿态在恒定角动量下调节翻转/转体速率，入水角度与手位决定水花，7 名裁判按
空中姿态、打开时机、水花三维度打分。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建
npm test         # 34 项物理/会话验收测试（Vitest）
```

## 四个页面

1. **选动作** `src/ui/selectPage.ts`：3 种虚构身材运动员 + 14 个 FINA 风格动作（含 207C、109B、5253B 等）。
2. **跳台** `src/ui/platformPage.ts`：蹬台力度/前倾/转体三滑块决定起跳冲量与角动量；空中手动切换团身/屈体/打开；
   另有自动示范模式（规划器闭环控制）。
3. **慢放分析** `src/ui/analysisPage.ts`：0.15×–1× 回放、角动量/惯量/角速度曲线、三姿态理论周数比、守恒偏差、逐帧数据。
4. **裁判打分** `src/ui/judgePage.ts`：7 裁判去最高最低取中间 5 个，三维度子分，总分 = 执行均值 × 难度系数 × 3。

## 物理模型（`src/physics/`）

- `bodyModel.ts`：Hanavan 风格比例模型，每节为圆杆，给出质量与主轴惯量；3 种身材参数。
- `kinematics.ts`：姿态自由度（髋/膝/肘/肩/低头/偏轴手臂）驱动的正向运动学；
  组装绕全身质心的惯量张量 `Iroot` 与姿态内部角动量矩阵 `A`（结果按姿态缓存）。
- `dynamics.ts`：核心求解器。腾空中每步由守恒约束
  `H_body = Iroot·ω_body + A·q̇` **反解根角速度**，因此总角动量在机器精度内恒定；
  姿态变化只在 `Iroot` 与内部项之间重新分配——团身惯量小转得快、打开惯量大涨速自然下降。
  转体用独立守恒的轴向角动量 `Hyaw` 建模（绕身体纵轴的偏航自由度），偏轴手臂微调轴向惯量。
- `divePlanner.ts`：代数估值 + 仿真内回路网格标定，自动反推每个动作的起跳冲量、角动量与打开阈值。
- `scoring.ts`：水花模型 `splash ∝ (入水角/10°)² + 残留角速度 + 非手先入水惩罚`，超 10° 明显罚分。

## 需求验收对应

| 需求 | 验收测试 |
| --- | --- |
| 三姿态周数比与惯量比一致（误差 ≤5%） | `physics.test.ts` 对 3 名运动员分别校验仿真翻转角比 vs `1/Izz` 理论比 |
| 空中总角动量守恒 | 独立 FK 重算节段角动量，全过程相对偏差 < 2e-4；线动量半隐式解析解 < 1e-12 |
| 207C/109B 等动作可完成 | 14 个动作全部规划成功，周数达标、飞行时间 1–2.8s |
| 入水角 >10° 水花分明显下降 | 2°/15°/30° 单调显著增大；端到端失误跳总分 < 完美跳 ×0.7 |
| 多身材参数 | 力量型 1.78m/72kg、灵巧型 1.64m/52kg、少年型 1.52m/42kg，惯量随身材变化 |

## 关键物理事实

- 翻转（绕冠状轴）惯量：团身 < 屈体 < 直体，故团身翻转最快。
- 转体（绕身体纵轴）惯量顺序相反：屈体 > 团身 > 直体（折叠的四肢偏离纵轴），故直体转体最快——
  这与真实跳水生物力学一致，两个转轴的趋势本就不同。
